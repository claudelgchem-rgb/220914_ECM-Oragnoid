### 2-2. 중복 검사 — 반려 2건

`material_id`·`essential_id` 자체의 중복은 **0건**이다. 문제는 **ID는 다르되 실체가 같은 물질**이다.

물질명(`name_ko`, `name_en`)에서 괄호·공백·하이픈·중점을 제거해 정규화한 뒤 군집한 결과, 다중 ID 군집 16개가 나왔다. 이를 `supplier`·`catalog_no`·`spec`으로 하나씩 대조해 **정당한 구분 10건**과 **실질 중복 6건**으로 갈랐다.

**정당한 구분(반려하지 않음)** — 분자량·유래·등급이 실제로 다른 별개 품목이다.
히알루론산 3건(21~40K / 100~185K / 1.01~1.8M Da), 알지네이트 3건(고G 중점도 / 고G 저점도 / 고M), 키토산 2건(중·저분자량), 콜라겐 IV형 2건(마우스 EHS / 인간 태반), 라미닌-111 2건(천연 / 재조합), 기저막추출물 2건(Corning / Cultrex), mTG 2건(연구용 / 식품등급), 아텔로콜라겐 2건(ABM 3 mg/mL / Koken 5 mg/mL).

**실질 중복(반려-004)** — 아래 6쌍은 공급사·품번·규격이 겹치거나 동일 분자를 층위만 바꿔 두 번 등재한 것이다. 상세는 4절에 적는다.

### 2-5. R-10 역할 혼동 검사 — 전수 검사 완료, 반려 1건

| **검사 체계 신뢰성** | **`validate.py`가 반려 8건을 전부 미탐지** | **미충족([반려-009])** |

**판정: 실패.** 15개 기준 중 9개 충족, **6개 미충족**이다.

실패의 핵심은 단일하다 — **하니스가 R-10을 가장 잘 아는 곳(`01_`:55 절 제목, `11_`:202~208, `essential_matrix.csv` AX-6 8개 조직 전부, `04_`:95 비교표, HTML 본문의 "이 보고서는 이를 엄격히 분리해 표기했다")에서 정확히 선언해 놓고, `material_inventory.csv`의 `essentiality` 열 6개 셀에서 그 선언을 어겼으며, 그 6개 셀이 최종 HTML의 층위 요약표 "필수 등재" 수치로 출력된다.** 원인은 `essentiality` 필드에 판정 기준이 정의되지 않은 것([반려-005])이고, 이를 걸러낼 자동 검사가 없는 것([반려-009])이다. 세 반려는 하나의 사슬이며, [반려-005]의 기준 정의와 [반려-009]의 R-10 규칙 추가가 나머지를 연쇄적으로 해소한다.

정정 대상은 `material_inventory.csv` 6셀 + 중복 6군 병합 + `11_`:60 한 문장 + `essential_items.csv` 2행 하향 + `patents_landscape.csv` 3셀로, 산출물 전체의 구조나 근거 기반을 다시 만들 필요는 없다. 근거 무결성(날조 인용 0, 대장 미등재 0), R-13 핵심 위반 0건, R-03 0건, §4 0건은 확인되었다.
