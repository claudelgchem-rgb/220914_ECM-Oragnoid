# 그림 설계 메모 (figure specs)

본 보고서의 **모든 그림은 인라인 SVG로 직접 제작**했다(R-14).
외부 이미지 파일, 논문·제조사 도판의 복제·링크 삽입은 사용하지 않았다.
이 문서는 각 그림의 원 수치와 출처를 남겨 추적 가능하게 하기 위한 것이다.

- **데이터 기준일**: 2026-09-14
- **생성 코드**: `tools/figlib.py`(공통), `tools/figs_concept.py`, `tools/figs_struct.py`,
  `tools/figs_m3.py`, `tools/figs_misc.py`
- **색 제한**: 5색 이내 + 범례 필수. 색맹 대응을 위해 패턴(빗금·점)과 등급 글자를 병행한다.
- **원칙**: 근거 없는 수치는 그리지 않는다. 근거가 없으면 '정량 근거 없음'으로 표시한다.

## 5. 접근성 고려

- 모든 등급 표시는 **색 + 패턴 + 글자** 세 가지로 중복 부호화했다. 색각 이상이 있어도 등급을 읽을 수 있다.
- 각 `<svg>`에 `role="img"`와 `aria-label`을 부여했다.
- 뷰박스 기반 `width=100%`로 좁은 화면에서도 비율을 유지하며 축소된다.
- 인쇄 시 배경을 제거하고 테두리를 남기도록 `@media print`에서 처리했다.
