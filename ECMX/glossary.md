# 용어 풀이집 (glossary)

본문에서 처음 등장하는 전문용어·약어에 붙인 한 줄 풀이를 모은 것이다(R-09).
유변학(재료의 변형과 흐름을 다루는 학문)과 단백질 발현·정제, 규제 용어는
비전공자 기준으로 다시 풀어 썼다. 줄임말은 최소화했다.

- **데이터 기준일**: 2026-09-14

| 용어 | 뜻 |
|---|---|
| **세포외기질 (extracellular matrix, ECM)** | 조직 안에서 세포 사이를 채우는 단백질·당의 그물. 세포를 붙들 뿐 아니라 어디에 붙고 얼마나 자라고 무엇으로 분화할지를 지시한다. |
| **매트리솜 (matrisome)** | ECM을 이루는 부품 전체의 목록. 단백질체학으로 정의된 참조 체계다. |
| **기저막 (basement membrane)** | 상피세포층 바로 아래에 깔린 얇고 치밀한 판상 ECM. 라미닌·4형 콜라겐·니도젠·퍼레칸이 주성분이다. |
| **오가노이드 (organoid)** | 줄기세포가 3차원 환경에서 스스로 조직 구조를 만들어 낸 배양체. 단순히 뭉친 세포 덩어리(스페로이드)와 구분된다. |
| **하이드로겔 (hydrogel)** | 물을 대량으로 머금은 고분자 그물. 오가노이드 배양 매트릭스는 대부분 하이드로겔이다. |
| **지지체 (scaffold)** | 세포가 자랄 자리를 제공하는 구조물 전반. 하이드로겔보다 넓은 개념이며 섬유·다공성 고체도 포함한다. |
| **인테그린 (integrin)** | 세포막에 박혀 기질을 붙잡는 수용체. 어느 인테그린이 있느냐에 따라 붙을 수 있는 리간드가 달라진다. |
| **접착 리간드 (adhesion ligand)** | 인테그린이 결합하는 자리. 전장 단백질이 제공할 수도, 짧은 펩타이드 조각이 제공할 수도 있다. |
| **RGD** | 아르기닌-글리신-아스파르트산 세 글자 서열. 여러 ECM 단백질에 공통으로 있는 대표적 인테그린 결합 모티프다. |
| **IKVAV / YIGSR** | 라미닌에서 유래한 접착·신호 모티프. 각각 α1 사슬, β1 사슬에서 왔다. |
| **GFOGER** | 콜라겐에서 유래한 모티프로 인테그린 α2β1에 선택적으로 결합한다. |
| **라미닌 아이소폼 (laminin isoform)** | 라미닌은 α·β·γ 세 사슬이 조합된 단백질이며, 조합에 따라 번호가 붙는다. 예: 라미닌-511 = α5β1γ1. |
| **E8 절편 (E8 fragment)** | 라미닌에서 인테그린 결합 활성을 가진 최소 단위만 잘라 낸 재조합 절편. 전장 단백질보다 생산이 쉽다. |
| **니도젠 / 엔탁틴 (nidogen / entactin)** | 라미닌 그물과 4형 콜라겐 그물을 이어 주는 연결 단백질. 같은 분자의 다른 이름이다. |
| **퍼레칸 (perlecan)** | 헤파란황산이 붙은 대형 프로테오글리칸. 성장인자를 붙잡아 두는 역할을 한다. |
| **저장탄성률 (storage modulus, G′)** | 겔에 주기적인 변형을 줄 때 되돌아오는(탄성) 성분의 크기. 쉽게 말해 '단단함'이며 단위는 파스칼(Pa)이다. |
| **손실탄성률 (loss modulus, G″)** | 같은 시험에서 열로 흩어지는(점성) 성분의 크기. G′와 함께 재료가 고체에 가까운지 액체에 가까운지를 알려 준다. |
| **영률 (Young's modulus, E)** | 잡아당기거나 누를 때의 단단함. G′와는 다른 물리량이며 단순 환산할 수 없다. |
| **응력완화 (stress relaxation)** | 겔을 일정하게 변형시킨 채 두었을 때 버티는 힘이 시간에 따라 줄어드는 현상. 생체 조직은 대부분 이 성질을 가진다. |
| **점탄성 (viscoelasticity)** | 탄성(되돌아옴)과 점성(흘러감)을 함께 가진 성질. 순수 탄성 겔과 생체 조직의 결정적 차이다. |
| **선형점탄성영역 (linear viscoelastic region, LVER)** | 변형이 작아서 재료 성질이 변형 크기에 따라 달라지지 않는 구간. 물성 측정은 이 안에서 해야 유효하다. |
| **유변계 진동측정 (oscillatory rheometry)** | 시료에 주기적 변형을 주어 G′·G″를 재는 방법. 평행판 방식이 흔하다. |
| **원자간력현미경 (atomic force microscopy, AFM)** | 미세 탐침으로 표면을 눌러 국소 탄성률을 재는 방법. 유변계와 측정 대상 크기가 달라 값이 다르게 나올 수 있다. |
| **기질금속단백분해효소 (matrix metalloproteinase, MMP)** | 세포가 분비해 ECM을 자르는 효소. 겔에 이 효소가 자를 서열을 심으면 세포가 스스로 길을 낸다. |
| **분해성 (degradability)** | 세포가 기질을 잘라 내며 공간을 넓힐 수 있는 성질. |
| **가교 (crosslinking)** | 고분자 사슬들을 서로 이어 겔로 만드는 것. 화학·효소·빛·이온 등 여러 방식이 있다. |
| **트랜스글루타미네이스 (transglutaminase)** | 글루타민과 라이신 사이에 결합을 만드는 효소. 세포가 있는 상태에서도 온화하게 겔을 굳힐 수 있다. |
| **비닐설폰 (vinyl sulfone)** | 티올기와 온화한 조건에서 선택적으로 결합하는 반응성 작용기. PEG 말단에 붙여 가교에 쓴다. |
| **다분지 폴리에틸렌글리콜 (multi-arm PEG)** | 중심에서 여러 갈래로 뻗은 PEG. 갈래 끝에 반응기를 달아 그물을 만든다. |
| **자기조립 펩타이드 (self-assembling peptide)** | 특정 조건에서 스스로 섬유를 이루어 겔이 되는 짧은 펩타이드. |
| **메타크릴레이트화 젤라틴 (GelMA)** | 젤라틴에 메타크릴기를 붙여 빛으로 굳을 수 있게 만든 재료. |
| **광개시제 (photoinitiator)** | 빛을 받아 라디칼을 만들어 중합을 시작시키는 물질. 세포 독성이 낮은 것을 골라야 한다. |
| **탈세포화 세포외기질 (decellularized ECM, dECM)** | 조직에서 세포만 제거하고 남긴 기질. 조직 고유 조성을 유지하지만 공여체마다 다르다. |
| **기저막추출물 (basement membrane extract, BME)** | 마우스 종양에서 추출한 가용화 기저막. 저온에서 액체, 체온에서 겔이 된다. |
| **극성 (apicobasal polarity)** | 상피세포가 안쪽(내강 쪽)과 바깥쪽(기저막 쪽)을 구분해 방향을 잡은 상태. |
| **싹눈 (budding)** | 구형 오가노이드가 바깥으로 돌기를 내미는 것. 장에서는 크립트 구조로 이어진다. |
| **크립트 (crypt)** | 장 상피의 움푹 들어간 구조로 줄기세포가 자리 잡는 곳. |
| **내독소 (endotoxin)** | 그람음성균 세포외막의 지질다당류. 미량으로도 세포 반응을 교란하는 발열성 물질이며 EU 단위로 관리한다. |
| **LAL 시험 (Limulus amebocyte lysate assay)** | 투구게 혈구 추출물로 내독소를 검출하는 시험법. 재조합 C인자(rFC)법이 대체법으로 쓰인다. |
| **연구용 등급 (Research Use Only, RUO)** | 연구 목적으로만 판매되는 등급. 임상용으로 쓰려면 별도 요건을 갖춰야 한다. |
| **의약품 제조 등급 (GMP grade)** | 의약품 제조 및 품질관리 기준을 충족해 생산·문서화된 등급. |
| **부자재 (ancillary material)** | 최종 제품에 남지 않지만 제조 과정에 쓰이는 재료. 세포치료제 제조에서 매트릭스가 여기 해당할 수 있다. |
| **전염성 해면상 뇌증 (TSE/BSE)** | 반추동물 유래 원료에서 문제가 되는 프리온 질환. 동물 유래 원료 규제의 핵심 근거다. |
| **독립항 (independent claim)** | 다른 항을 인용하지 않고 그 자체로 권리 범위를 정하는 청구항. 필수 구성요소가 여기에 적힌다. |
| **우선일 (priority date)** | 동일 발명에 대해 최초로 출원한 날. 신규성 판단의 기준이 된다. |
| **국제특허분류 (IPC)** | 특허를 기술 분야별로 나눈 국제 분류 체계. |
| **자유실시 (freedom to operate, FTO)** | 어떤 기술을 실시할 때 타인의 특허를 침해하지 않는지에 대한 판단. |
| **제거 실험 (omission experiment)** | 어떤 성분을 뺀 조건과 넣은 조건을 비교하는 실험. 이 보고서가 '필수' 판정에 요구한 근거 유형이다. |
| **치환 실험 (substitution experiment)** | 어떤 성분을 다른 것으로 바꿔 보는 실험. 대체 가능성을 판정하는 근거가 된다. |
| **농도 반응 (dose response)** | 농도를 바꿔 가며 효과를 보는 실험. 필요 농도 범위를 알려 준다. |

## 특히 혼동하기 쉬운 세 쌍

### 1. 배지(medium) 성분 ↔ 매트릭스(matrix) 성분
배지는 액체로 갈아 주는 것, 매트릭스는 세포가 박혀 있는 겔이다.
표피성장인자(EGF), 노긴(Noggin), 알스폰딘(R-spondin), Wnt3a 등은 거의 예외 없이 **배지** 성분이다.
이들을 '오가노이드 지지체의 필수 성분'으로 적는 것은 범주 오류다.

### 2. 2차원 코팅 기질 ↔ 3차원 하이드로겔
배양접시에 얇게 바르는 라미닌·비트로넥틴 코팅과, 세포를 사방에서 감싸는 겔은 다른 물건이다.
2차원에서 작동한 리간드가 3차원에서도 같은 역할을 한다는 보장이 없다.

### 3. 체외 배양용 지지체 ↔ 체내 이식용 전달 매트릭스
요구 규격과 규제 경로가 다르다. 예컨대 글루타르알데하이드로 가교한 재료는
체내 이식재로는 쓰이지만 세포를 넣은 채 굳히는 데는 쓸 수 없다.

## 물리량 혼동 주의

| 구분 | 저장탄성률 G′ | 영률 E |
|---|---|---|
| 무엇을 재나 | 주기적 전단 변형에 대한 탄성 응답 | 잡아당기거나 누를 때의 강성 |
| 대표 측정법 | 유변계 진동측정(평행판) | 인장·압축시험, 원자간력현미경 |
| 단위 | 파스칼(Pa) | 파스칼(Pa) |
| 상호 환산 | **단순 환산 불가.** 포아송비와 재료 가정이 필요하며, 하이드로겔에서는 가정이 잘 성립하지 않는다 |

단위가 같다는 이유로 두 값을 같은 축에 놓고 비교하는 것은 흔한 오류다.
본 보고서의 물성 표와 그림에는 각 수치의 측정법을 함께 적었다.
