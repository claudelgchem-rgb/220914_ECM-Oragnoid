## 핵심 결론

이 조사는 "필수"라는 단어에 **증거 기준**을 걸었다. 어떤 성분을 필수라 부르려면 그 성분을
**뺀 조건과 넣은 조건을 비교한 실험**이 논문 본문에 있어야 하며, 총설이나 제조사 자료의
서술만으로는 인정하지 않았다. 그 기준을 적용한 결과:

| 발견 | 내용 |
|---|---|
| **절대 필수(E0)는 2건뿐** | 둘 다 특정 단백질이 아니라 **β1·α6β1 인테그린 매개 접착**이라는 기능이다 |
| **"라미닌이 필수"는 부정확** | 정확한 명제는 "α6β1 인테그린이 결합할 수 있는 무언가가 필수이고 라미닌-111은 그 대표 리간드"다 |
| **기저막 4대 성분 중 셋은 근거 부재** | 4형 콜라겐·니도젠·퍼레칸은 외인성 보충의 필수성 근거를 찾지 못해 E3 |
| **강성·점탄성은 E0에 도달하지 못했다** | 중요하지 않아서가 아니라, 요구 범위가 조직과 배경 고분자에 따라 두 자릿수 달라지기 때문이다 |
| **원천 특허는 만료** | 기저막 매트릭스 조성·제법 특허(US4829000A / EP0218065B1)는 2006년 만료로 공중영역 |

등급 분포: **E0 2 / E1 39 / E2 44 / E3 9** (총 94건, AX-1~AX-9 아홉 축 전부 조사)

## 근거 원칙

- 논문 서지는 **Europe PMC 직접 조회**로 확정했고, 인용 식별자를 전수 대조했다. 날조 인용 0건.
- 오픈액세스 **전문 133편**을 내려받아 본문을 직접 확인했다. 전문을 못 읽은 논문은
  `본문 미확인`으로 표기하고 실험 조건을 추정 서술하지 않았다.
- 특허는 **청구항 원문 104건**을 취득해 독립항을 직접 읽었다. 요약서 기반 추정은 하지 않았다.
- 물성 수치에는 **단위와 측정법**을 반드시 병기했다. 저장탄성률(G′)과 영률(E)은 단순 환산이 불가능하다.
- 배지 성분과 매트릭스 성분, 2D 코팅과 3D 하이드로겔, 체외 배양용과 체내 이식용을 구분해 표기했다.
